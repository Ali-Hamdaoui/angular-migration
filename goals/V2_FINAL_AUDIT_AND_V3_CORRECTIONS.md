# V2 Final Audit and V3 Corrections

V2 was structurally strong but not safe as the final execution package. V3 corrects the following verified defects:

1. **Contaminated code inventory:** V2 counted 706 files because a stale extraction contained generated bytecode/cache. V3 inventories the source ZIP directly: 478 files and no cache anchors.
2. **Unsupported Hermes setting:** removed `delegation.max_iterations`; V3 uses `agent.max_turns`, `goals.max_turns`, and documented delegation keys.
3. **Goal 10 contradiction:** V3 separates Phase A `harness_ready` from Phase B `integration_verified`; AMFA-225 cannot be marked complete on the unintegrated branch.
4. **Backlog extraction overflow:** V2 appended backlog appendices E–J to S4-F15/T04. V3 ends S4-F15 before `# E.` and recomputes source checksums.
5. **Unconditional five-agent cycle:** fixer and re-review are now conditional on reviewer failure; planner, implementer, and independent reviewer remain mandatory.
6. **Mutable base-lock risk:** worktree creation now writes an immutable JSON lock and aborts on base drift instead of overwriting it.
7. **Weak existing-worktree checks:** V3 validates branch, ancestry, remote, root instruction hash, session identity, runtime ownership, and goal presence.
8. **Linux VM gaps:** V3 checks Python 3/venv and required tools, defines per-worktree environment preparation, and records the Linux/Windows evidence boundary.
9. **Parallel Hermes backend risk:** V3 requires local terminal backend and prohibits unrestricted yolo mode.
10. **Thin handoff registry:** V3 adds approval, lease, log, bootstrap, changed-risk, gate-result, repair-state, source-integrity, session-identity, and integration-proof schemas.
11. **Manual versus human acceptance:** V3 records human product sign-off separately and requires it for integrated high-risk product acceptance.
12. **Live code truth:** fresh source inventory includes exact top-level symbols, while every goal still must re-audit the VM worktree.

V3 retains the verified V2 strengths: ten capability goals, all 29 Sprint 3/4 features, all 116 Jira subtasks, exact authoritative dependency graph, external runtime isolation, task-level contracts, manual scenarios, documentation agent, final auditors, and assigned-branch push rules.
