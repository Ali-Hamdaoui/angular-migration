This workspace contains the product specification, workflow rules, sprint
backlog, architecture notes, ADRs, and local setup guidance.

The current source documents are:

- `mvp_overview.md` - MVP scope and product decisions.
- `workflow.md` - migration workflow, safety rules, and artifact model.
- `sprint0.md` - Sprint 0 backlog and implementation order.
- `adr/` - accepted Sprint 0 architecture decision records.
- `threat-overview.md` - Sprint 0 threat overview and mitigations.
- `code-review-checklist.md` - ADR-linked review checklist.
- `open-architecture-questions.md` - deferred architecture decisions.
- `sprint0-demo.md` - demo boundary notes.

Keep documentation aligned with implementation decisions, especially execution
authority, sandbox-only mutation, and backend-owned workflow state.
