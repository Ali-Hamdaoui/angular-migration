# As-Built Documentation Standards

After runtime green, document actual final code under `docs/capabilities/<goal>/`: README, architecture/workflow, backend, frontend, API/events, data model, operations, testing/manual proof, security, troubleshooting, limitations, and justified ADRs.

Use exact paths, symbols, endpoints, events, tables, commands, commit SHA, and evidence. Do not claim unexecuted tests or hide limitations. The Documentation Agent edits docs/evidence only. Implementation mismatch returns to coding.
